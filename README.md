# Acer Nitro Control & Smart Fan for Linux 🚀

Полнофункциональный комплекс мониторинга системы, аппаратного управления кулерами и умного охлаждения для ноутбуков **Acer Nitro 5 (включая AN515-45, AN515-46, AN515-55/57/58)** под Linux (Arch, Fedora, Ubuntu, Debian).

Разработано специально для связки **AMD Ryzen + NVIDIA GeForce RTX** и окружений Wayland (Hyprland, GNOME, Sway) и X11.

---

## 🌟 Возможности

### 1. Управление кулерами и охлаждением
- **Обороты вентиляторов в реальном времени (RPM)**: раздельное чтение реальных скоростей кулеров процессора (CPU Fan) и видеокарты (GPU Fan) напрямую из Embedded Controller (EC).
- **Режимы обдува**:
  - 🔘 **Заводской (Тихий)** — тихий заводской алгоритм прошивки;
  - ⚡ **Умный Автофан** — фоновый демон непрерывного мониторинга: при нагреве свыше 72°C заранее повышает обдув, а при 82°C+ активирует максимальный режим ТУРБО для гашения температурных всплесков;
  - 🚀 **ТУРБО (100%)** — продувка ноутбука на полных оборотах кулеров (~5500+ RPM);
  - 🎛 **Ручное управление** — выделенный тумблер ручного режима с независимыми ползунками (20% – 100%) отдельно для CPU и GPU, с защитой от конфликта таймеров.

### 2. Мониторинг оперативной памяти (ОЗУ)
- Раздельный учет физической RAM, сжатого ZRAM Swap и аппаратного резерва VRAM для встроенного ядра AMD Radeon;
- **Живой список топ-8 процессов, расходующих больше всего ОЗУ** (с указанием PID, объема в МБ и процента памяти).

### 3. Нагрузка и распределение видеокарт (CPU & GPU)
- **Топ-8 процессов по нагрузке на процессор (CPU %)**;
- **Распределение графических адаптеров**:
  - *AMD Radeon Vega (iGPU)*: статус рендеринга рабочего стола и матрицы экрана;
  - *NVIDIA GeForce RTX (dGPU)*: статус энергосбережения **D3cold (0 Вт)** и список запущенных 3D-приложений на дискретной карте.

## 📦 Быстрая установка

```bash
git clone https://github.com/ВАШ_НИКНЕЙМ/acer-nitro-control.git
cd acer-nitro-control
sudo ./install.sh
```

---

## 🖥 Запуск

- **Из терминала:**
  ```bash
  nitro-control
  ```
- **Из меню приложений:** найдите **Acer Nitro Control**.

## 🛠 Архитектура проекта

- `bin/nitro-control` — современный графический интерфейс на **Python + GTK4 / Libadwaita** в темной теме.
- `bin/nitro-autofan.py` — легковесный фоновый демон динамического охлаждения.
- `systemd/nitro-autofan.service` — пользовательский systemd-юнит фонового автофана.
- `driver/` — DKMS-драйвер ядра `acer-nitro-ec` с поддержкой модели AN515-45.
- `desktop/` — ярлык `.desktop` для лаунчеров приложений.
